Client ID / Secret と質問先 Hub は、このブラウザにだけ保存します。ソースコードや GitHub には含まれません。

1. リダイレクトURI

Developer Console の OAuth 2.0 Redirect URI に、次の値をそのまま追加してください。

CORS Domains には、次の値をそのまま追加してください。Box AI の POST はこのオリジンを送ります。

2. アプリ資格情報

一度保存すると、次回からは自動で読み込みます。

3. 質問する Hub

ログイン後、サイドパネルの Hub タブで一覧から選ぶこともできます。ここでも ID を直接保存できます。

保存しました。次回からこの値を使います。

4. 必要なスコープ

  • Read all files and folders stored in Box（root_readonly）
  • Manage AI（ai.readwrite）

スコープを追加したら、Developer Console でアプリを再認可し、拡張機能側でいったん切断して再接続してください。

5. セキュリティとプライバシーに関する注意

  • Client Secretや認証トークンは、利用者のChrome内に保存されます。ソースコードや開発者のサーバーには送信しませんが、ローカルストレージは暗号化された秘密情報保管庫ではありません。共有PCや第三者が使えるChromeプロファイルでは使用しないでください。
  • 利用者が操作すると、選択テキスト・ページURL・ページタイトルがBox内検索やBox AIへの質問に使われます。機密情報を含む内容を送信する場合は、社内ルールを確認してください。
  • Boxから取得できる情報の範囲は、ログイン中のユーザーとBoxアプリに許可された権限に従います。必要な権限を確認したうえで利用してください。
